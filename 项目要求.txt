模块一：新闻晨报系统
功能：每日开盘前（例如 8:30）自动抓取财经新闻，调用 Claude API 分析，推送到钉钉。
实现要求：

使用 feedparser 库抓取至少 3 个 RSS 源（财联社、华尔街见闻、东方财富），每个源获取最近 10 条新闻标题和链接。

调用 Claude API（使用最新可用模型，不指定具体版本号，由系统自动选择）。构造提示词，要求模型输出固定 JSON 格式，包含：

bullish_sectors: 利好板块列表，每个元素含 name, strength(1-5), reason

bearish_sectors: 利空板块列表

mentioned_stocks: 提及的个股列表，含 code, name, reason

sentiment: 市场情绪（乐观/中性/悲观）

key_events: 关键事件列表（不超过5个）

将分析结果格式化为 Markdown，通过钉钉机器人 webhook 发送到指定群。

所有敏感信息（Claude API key、钉钉 webhook）从 config.yaml 读取。

提供 run_morning.py 可独立运行测试（也可集成到 main.py 通过 --morning 参数触发）。

模块二：风险预警模块
功能：在晨报基础上增加大盘风险评分与预警。
实现要求：

使用 akshare 或 tushare 获取以下实时/历史数据：

涨跌家数比（当天上涨家数/下跌家数）

昨日涨停股今日平均涨幅（需计算昨日涨停股池今日表现）

北向资金（沪股通+深股通）当日净流入额

上证指数当前位置相对于 20 日线、60 日线的偏离度

实现日历效应统计：基于过去 3 年的历史日线数据，计算周一至周五各自的下跌概率和平均涨跌幅，结果可缓存，每周更新一次。

设计风险评分模型，将上述指标量化为 0-10 分，总分映射为低风险(0-3)、中风险(4-6)、高风险(7-10)。阈值在 config.yaml 中可配置。

将风险预警结果（风险等级、主要扣分项、操作建议）作为晨报的一部分追加发送。

产出 risk_analyzer.py、calendar_stats.py，并集成到 run_morning.py 或 main.py 的晨报流程中。

模块三：策略回测与遗传算法进化
功能：在历史数据上自动搜索最优策略参数组合，定期生成策略报告。
实现要求：

策略模板：支持组合技术指标（SMA、EMA、RSI、MACD、量比）、持仓周期（1-5 天）、止盈止损百分比。所有参数可配置。

回测引擎：使用 vectorbt（优先）或 backtrader，支持日线数据，交易成本佣金 0.03%，滑点 0.1%，初始资金 100 万元。

遗传算法（使用 DEAP 库）：

每个个体为一个参数字典（例如 sma_short, sma_long, rsi_buy, rsi_sell, volume_ratio, hold_days, stop_loss, take_profit）。

适应度函数 = 年化收益率 * 0.4 + 夏普比率 * 0.3 - 最大回撤 * 0.2 + 胜率 * 0.1。

种群大小 50，进化代数 30，精英保留比例 20%，交叉概率 0.7，变异概率 0.1。

数据源：使用 akshare 获取过去 5 年（或可配置）全 A 股日线数据，为加速可先取沪深 300 成分股。

每周五 16:00 自动运行一次进化，生成策略进化报告，内容包括：当前最优参数、回测绩效指标（年化收益、夏普、最大回撤、胜率、交易次数）、与上周策略对比。报告推送到钉钉。

产出 strategy_evolver.py、backtest_engine.py、run_evolution.py，并集成到 main.py 的 --evolution 参数。

模块四：调度与整合
功能：将以上模块通过定时任务整合为全自动系统。
实现要求：

使用 schedule 库设置定时任务：

每个交易日 8:30 运行晨报+风险预警 → 推送钉钉

每个交易日 15:30 更新历史数据（行情、北向资金、涨停股列表）

每周五 16:00 运行策略进化 → 推送报告

所有定时任务的开关和时间在 config.yaml 中配置。

提供 main.py 统一入口，支持以下命令行参数：

--morning 仅运行晨报+风险预警

--risk 仅运行风险预警（不抓取新闻，只计算风险）

--evolution 仅运行策略进化

--update_data 仅更新历史数据

--all 按定时任务配置运行（常驻进程模式）

程序应能够常驻后台（可使用 while True + schedule.run_pending），并捕获异常后重试。
